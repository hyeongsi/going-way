# 가는김에 UI 참조 세트

이 폴더의 8개 이미지는 **가는김에** Android 앱의 화면 구현·디자인 검토를 위한 기준 시안이다. 이후 관련 작업에서는 이 문서와 이미지를 먼저 확인하고, 별도 지시가 없는 한 같은 시각 언어를 유지한다.

## 화면 목록

| 파일 | 화면 | 핵심 요소 |
|---|---|---|
| `01-home.png` | 홈 | 지도 요약, 퇴근길 추천, 주변 할 일, 오늘의 할 일, 하단 탭, 플로팅 추가 버튼 |
| `02-tasks.png` | 할 일 | 개인/공동 탭, 진행 상태, 할 일 카드, 완료 목록, 플로팅 추가 버튼 |
| `03-add-task.png` | 할 일 입력 | 3단계 등록 흐름의 1단계, 텍스트·음성 입력 |
| `04-place-selection.png` | 장소 선택 | 자동 추천 장소, 장소 검색, 3단계 등록 흐름의 2단계 |
| `05-alert-settings.png` | 알림 설정 | 퇴근길·지금 주변·둘 다 선택, 고급 설정, 3단계 등록 흐름의 3단계 |
| `06-shared-list.png` | 공동 목록 | 구성원 작성자 표시, 공동 할 일, 완료 목록 |
| `07-places.png` | 내 장소 | 상단 지도 요약, 집·회사·단골 마트 카드 |
| `08-nearby-alert.png` | 근처 도착 알림 | 완료·나중에·길 안내 빠른 선택 |

## 시각 원칙

- 따뜻한 아이보리 배경, 세이지 그린을 주요 강조색으로 사용한다.
- 전반적인 분위기는 친근하고 생활 밀착형이되, 화면 구조는 간결하게 유지한다.
- 큰 한국어 제목, 명확한 행동 버튼, 넉넉한 여백과 부드러운 라운드 카드가 핵심이다.
- 지도·일러스트는 정보를 보조하며, 할 일의 이름·상태·다음 행동이 항상 더 우선한다.
- 긍정 상태는 세이지 그린, 마감·보조 상태는 부드러운 옐로우/뉴트럴로 구분한다.
- 모바일 우선으로 설계하며, 하단 탭은 `홈`, `할 일` 두 항목을 기본으로 한다.

## 기능 원칙

- 새 할 일은 `할 일 입력 → 장소 선택 → 알림 설정`의 3단계로 등록한다.
- 알림은 할 일마다 시간대 시작·장소 근처·둘 다 중 선택한다.
- 개인 기능은 로그인 없이 가능하고, 공동 목록 진입 시 로그인한다.
- 위치는 추천 시점에만 사용하며 이동 이력은 저장하지 않는다.
